# Constants i variables

* **Definició**: Les **constants** són valors que no canvien durant l'execució del programa, mentre que les **variables** poden variar. És com si tinguéssim una "caixa" (variable) que podem obrir i canviar el contingut, mentre que la constant seria una caixa que no es pot modificar un cop definida.
* **Ús de constants**: Per exemple, si un programa gestiona una escola amb un màxim de 25 alumnes per classe, podem definir `CAPACITAT=25`. Això ens evita haver de modificar manualment cada lloc del codi quan aquest valor canvia.
* **Variables estàtiques i dinàmiques**: Les variables estàtiques existeixen durant tota l'execució, mentre que les dinàmiques només es creen i es destrueixen segons la necessitat, oferint més flexibilitat per gestionar memòria eficientment.
