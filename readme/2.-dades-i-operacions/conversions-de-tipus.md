# Conversions de tipus

De la mateixa manera que el fet de treballar amb dades impliqui que hi hagi d'haver unes operacions per fer-ho, també es genera la necessitat de tenir els mecanismes necessaris per poder convertir-les d'uns tipus a altres.

**Conversió explícita**: Es fa intencionadament pel programador. Per exemple, convertir un enter en un real:

```java
int a = 5;
float b = (float) a;
```

**Conversió implícita**: L'ordinador realitza automàticament la conversió quan és necessari, com en operacions entre un enter i un real.
