# Operadors

* **Aritmètics**: S'utilitzen per realitzar operacions matemàtiques bàsiques:
  * `+` (suma), `-` (resta), `*` (producte), `/` (divisió), `%` (mòdul o residu).
* **Relacionals**: Comparen dos valors:
  * `==` (igual), `!=` (diferent), `<`, `<=`, `>`, `>=`.
* **Lògics**: Treballen amb valors booleans:
  * `&&` (AND), `||` (OR), `!` (NO).
