# Dades compostes

Les **dades compostes** són estructures de dades que permeten agrupar múltiples valors en una sola entitat. A diferència de les dades simples, com `int` o `char`, que només emmagatzemen un sol valor, les dades compostes poden contenir múltiples elements i poden ser d’un mateix tipus (com els arrays) o de tipus variats (com les tuples o els objectes).&#x20;

Aquesta capacitat d’agrupar i organitzar dades és fonamental per escriure **codi més eficient**, **estructurat** i **llegible**.

Les dades compostes són especialment útils quan treballem amb col·leccions d'informació relacionades, com ara:

* Una llista d’estudiants d’una classe.
* Les vendes diàries d’un comerç.
* Coordenades en un sistema de geolocalització.

Aquestes estructures ens permeten gestionar, accedir i modificar grans quantitats de dades de manera eficient, evitant duplicacions i permetent un accés fàcil.

### Importància de les Dades Compostes

L’ús de dades compostes és essencial per diversos motius:

1. **Organització i estructuració**: Permeten agrupar dades relacionades de manera lògica, fent que el codi sigui més comprensible i estructurat.
2. **Eficiència**: Amb les dades compostes, podem accedir i gestionar col·leccions de dades amb operacions eficients. Això facilita, per exemple, la cerca o classificació d’elements en una llista.
3. **Escalabilitat**: Les estructures de dades compostes són ideals per a programes que necessiten gestionar grans volums de dades, ja que permeten escalar els programes de manera més senzilla.
4. **Modularitat**: Permeten crear mòduls de codi reutilitzables, com classes, que encapsulen dades i funcionalitats associades.
