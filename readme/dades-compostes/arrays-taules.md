# Arrays (Taules)

Les **taules** o **arrays**, són estructures que emmagatzemen un conjunt d’elements del mateix tipus. En els arrays, cada element té un índex que permet accedir-hi de manera directa.



<figure><img src="../../.gitbook/assets/image (1).png" alt="" width="310"><figcaption></figcaption></figure>

Podem distingir els arrays principalment segons les seves dimensions

### Unidimensionals (Vectors)

Un array unidimensional (també anomenat **vector**) és una llista lineal d’elements del mateix tipus. Cada element està identificat per un índex numèric, començant per 0.

**Declaració**

```java
int[] numeros; // Declarem un array d'enters
int[] edats = new int[5] // Declarem un array d'enters amb espai per 5 elements.
```
