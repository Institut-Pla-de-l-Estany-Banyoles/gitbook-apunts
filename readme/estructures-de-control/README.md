# Estructures de control

Les estructures de control són fonamentals en qualsevol llenguatge de programació, ja que permeten controlar el flux d'execució d'un programa. Aquestes estructures permeten condicionar l'execució de certs blocs de codi segons el valor de determinades expressions, repetir accions, o fins i tot gestionar errors.
