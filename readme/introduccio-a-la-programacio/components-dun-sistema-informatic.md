# Components d'un sistema informàtic

Un **sistema informàtic** és un conjunt de components electrònics, físics i lògics que treballen conjuntament per processar, emmagatzemar i transmetre informació.

* **Processador**: És el centre de control de l'ordinador, que manipula les dades a partir d'instruccions binàries.
* **Memòria**: Emmagatzema informació. Aquest pot ser persistent o temporal. Durant l'execució d'un programa, les dades que utilitza s'emmagatzemen de forma temporal principalment a la RAM.&#x20;
* **Entrada/sortida**: Permet interactuar amb l'exterior, ja sigui a través de teclat, pantalla o altres dispositius o busos.&#x20;
