# Conceptes inicials

## &#x20;Introducció a la programació

* **Programa**: És un conjunt d'ordres o instruccions que es processen de manera seqüencial. Alguns exemples de programes són els de les rentadores o robots de cuina, que executen tasques específiques de manera ordenada.&#x20;

{% hint style="info" %}
En el nostre cas, els nostres programes s'executaran sobre un[ sistema informàtic](components-dun-sistema-informatic.md).
{% endhint %}

*   **Algorismes**: Són mètodes per resoldre problemes amb un seguit de passos finits. Un exemple senzill seria un algorisme per fer una truita, amb una seqüència de passos.&#x20;

    Podem imaginar-nos com un manual d'instruccions. Si estàs muntant un moble d'IKEA, el manual et diu com muntar-lo pas a pas.&#x20;

{% hint style="info" %}
Un algorisme per escalfar l'aigua seria:

1. Agafar una olla.
2. Posar-hi aigua.
3. Encendre el foc.
4. Esperar fins que bulli.
{% endhint %}

* **Llenguatges de programació**: Cada llenguatge de programació defineix el seu conjunt de normes sintàctiques i semàntiques que s'han de complir perquè l'ordinador pugui interpretar quines operacions ha de fer.
* **Codi font:**&#x20;
* **IDE (Integrated Development Environment):** O Entorn de Desenvolupament Integrat, és el programa informàtic que ajuda i assisteix en la creació de nous programes.
