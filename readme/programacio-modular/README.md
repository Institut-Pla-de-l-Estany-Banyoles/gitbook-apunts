# Programació modular

La **programació modular** és una tècnica que divideix un programa en parts més petites i gestionables anomenades **mòduls** o **mètodes**. Cada mòdul s'encarrega d'una tasca específica, fet que facilita el desenvolupament, el manteniment i la reutilització del codi.

{% hint style="info" %}
### Avantatges

1. **Estructuració**: El programa queda dividit en unitats lògiques. el que millora la claredat del codi. Dividir el codi en mòduls fa que el programa sigui més llegible i comprensible.
2. **Depuració**: És més fàcil detectar i corregir errors dins d'un mètode específic.
3. **Reutilització**: Els mètodes es poden cridar diverses vegades en diferents llocs del programa i poden ser reutilitzats en diferents projectes.
4. **Escalabilitat**: Els programes modulars són més fàcils d'expandir amb noves funcionalitats.
5. **Manteniment**: Les modificacions es poden fer en un únic lloc sense afectar la resta del programa.
6. **Col·laboració**: Permet que diferents desenvolupadors treballin en mètodes diferents de manera independent.
{% endhint %}

***

Una de les principals maneres per poder aplicar programació modular a les nostres aplicacions és mitjançant **disseny descendent**. Consisteix a descompondre el problema principal en subproblemes més petits i treballar en la solució de cada subproblema.&#x20;

Podem veure com que segueix el principi de _“divideix i venceràs”_. Dividim el problema principal en subproblemes, si aquests encara són prou complexes de resoldre, els dividim de nou amb diversos subproblemes més simples.
