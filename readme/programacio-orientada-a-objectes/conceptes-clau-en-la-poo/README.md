# Conceptes clau en la POO

La **Programació Orientada a Objectes (POO)** és un paradigma de programació que es basa en l’ús d’**objectes** per estructurar el codi i organitzar les funcionalitats d’un programa. Tres **conceptes fonamentals** de la POO són:

1. [**Encapsulació**](encapsulacio.md)
2. [**Herència**](herencia.md)
3. [**Polimorfisme**](polimorfisme.md)
